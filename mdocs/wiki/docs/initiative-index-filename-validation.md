# Initiative INDEX filename validation

Initiative INDEX validation must parse only the filename field from canonical rows:

`- **Title** (status) — filename.md — YYYY-MM-DD — [tags]`

Do not scan whole INDEX content for `.md` tokens. Titles may legitimately mention markdown filenames such as `overview.md`, `log.md`, or `index.md`; those tokens are not listed initiative files.

Shared parser behavior:
- split INDEX content by line
- take field after first em dash
- trim it
- accept only safe markdown filenames matching `/^[\w.-]+\.md$/`
- ignore `INDEX.md`

This preserves real warnings for missing filename-field entries while preventing false positives from title prose.
