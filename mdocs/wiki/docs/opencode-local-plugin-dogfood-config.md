# OpenCode local plugin dogfood config

For this repository, `.opencode/opencode.jsonc` should load the local built plugin rather than a published npm version:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["../dist/surfaces/opencode/opencode.js"]
}
```

Rationale:
- published plugin pins can lag behind local source fixes
- local dogfooding should exercise current checkout behavior
- `dist/surfaces/opencode/opencode.js` preserves the expected `__dirname` layout for resolving repo-root `agents/` and `skills/`

After config changes, restart OpenCode. Config and plugins are loaded at startup, not hot-reloaded.
