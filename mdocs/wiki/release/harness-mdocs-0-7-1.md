# harness-mdocs 0.7.1

Patch release fixing initiative INDEX filename validation and synchronizing the bundled Claude Code plugin runtime.

## Fixed

- Initiative INDEX titles containing Markdown-looking tokens such as `overview.md`, `log.md`, or `index.md` no longer produce false missing-file warnings.
- Initiative validation and consistency checks parse only the canonical filename column from INDEX rows.
- Regression coverage preserves genuine missing-indexed-file diagnostics while ignoring filename-like title text.
- Bundled Claude Code plugin runtime and declarations include the same parser behavior as core.

## Repository-only change

- OpenCode dogfood configuration moved from stale `harness-mdocs@0.4.0` to the local built plugin. This configuration was not part of the npm package API.
