Minor release shipping safe metadata-only mutations and stronger directory-v2 integrity diagnostics.

## Added
- Lossless wiki updates retain consumer frontmatter, aliases, path-style IDs, singular categories, body content, and line endings.
- Mutation commands normalize snake_case/camelCase fields, report applied/skipped/unsupported fields, and verify successful writes by reading them back.
- `wiki.link` performs verified bidirectional persistence, rolls back partial mutations, and skips own compiled-page self-links.
- Directory-v2 validation detects missing compiled pages, status drift, external index/overview omissions, invalid identities, asymmetric links, and self-links.

## Changed
- `wiki.ingest` reports aggregate failure when any operation fails.
- `wiki.xref` validates exact existing targets and reports directed semantics accurately.
