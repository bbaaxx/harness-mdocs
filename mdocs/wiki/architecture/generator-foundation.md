## Purpose
WP-105 makes generated agent assets deterministic and transactionally recoverable. Surface teams stop hand-editing managed mirrors.

## Model
- Canonical prompt fragments under `src/generation/fragments/`; explicit source-to-output manifest covering all 4 surfaces (27 outputs).
- Sidecar provenance manifest records byte digests, provenance, generator/schema versions.
- `generateAssets` / `checkGeneratedAssets` APIs; `scripts/generate-agent-assets.js` compiles exact source into a temp dir (never stale dist) then runs `--generate` or `--check`.
- Check mode is strictly read-only and reports missing, byte-drifted, provenance-drifted, stale, and pending-transaction outputs.
- Generate mode serializes via portable lock (`{pid, bootToken, nonce}`, no shell-out), pins parent inodes through cwd-segment navigation with bigint dev/ino checks and no-follow opens, stages bytes, journals phases (prepared/applying/committed/cleaning), and commits atomically (no-replace hard link for creates, journaled backup for replacements).
- Stale deletion requires code-owned managed-root namespace plus prior-manifest exact digest proof; forged self-hashed manifests cannot delete arbitrary files. Temp cleanup requires path + dev/ino + byte digest + per-transaction secret proof.

## Invariants
- Repeat generation is byte-identical and mtime-stable for unchanged files.
- Crash recovery uses journaled state before reading canonical sources; interrupted transactions roll back or finish cleanup without wedging.
- Live PID + matching bootToken never yields lock takeover regardless of heartbeat age; PID reuse cannot steal a lock.
- Case-insensitive filesystem collisions and same-inode case entries rejected; portable fold only detects collisions, never containment.
- Windows skips unsupported directory fsync/POSIX mode enforcement but keeps file fsync and journal ordering.

## Integration
- `npm run generate:agents` and `npm run check:agents`; check runs in `quality` before lint/tests. `.mdocs-generation.boot` is machine-local and gitignored.
