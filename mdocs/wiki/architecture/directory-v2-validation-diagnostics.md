## Summary
GitHub issue #8 P1 adds contract-aware, read-only validation diagnostics for directory-v2 consumer schemas.

## Rules
- Directory initiative validation discovers immediate `initiatives/*/_status.md` records.
- Active directory initiatives require a compiled `wiki/initiatives/<id>.md` (or compatible singular-category) page with status matching normalized source status.
- With `wikiIndexOwner: external`, curated `wiki/index.md`, `initiatives/INDEX.md`, and `wiki/overview.md` are parsed read-only. Missing link membership is reported without rewriting any compiled view.
- Markdown destinations and closed inline-code path entries are accepted. Categorized artifacts require category-qualified references; bare IDs mean root pages only.
- Graph validation detects asymmetric links, self links, alias-mediated self links, identity/category mismatches, and source/page status drift while preserving valid path-style IDs and singular category aliases.
- `wiki.ingest` now fails aggregate success when an operation fails. `wiki.xref` validates exact existing targets and reports directed semantics accurately.
