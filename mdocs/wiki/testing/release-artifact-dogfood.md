# Release artifact dogfood

Test the packed artifact from a scratch consumer project, not only source imports. Verify the embedded version and git SHA, MCP initialize/tools/list handshake, CLI JSON results and nonzero failure exits, and memory root resolution. Build-time fingerprints avoid relying on the consumer git checkout.

Initiative creation intentionally does not activate work: follow the returned hint with resume. Validate after CLI mutations and verify on-disk state. The September 2026 dogfood records established these contracts before the 2.0.0 release; no new historical test results are asserted here.
